🎯 Test Sistema Riferimenti Posizioni Originali

Sistema esteso per riferimenti _original in animazioni e drag & drop

Versione: Novembre 2025 | Integrazione: AnimationSystem + DragDropSystem

📋 Panoramica Funzionalità

Il sistema permette di riferirsi alle posizioni originali dei modelli 3D usando la sintassi _original:

Esempi di utilizzo:

Animazioni:
Azione1=traslazione:tappino_grasso_dx_original,(0,0,0,0.8)

Drag & Drop:
DragDropSystem.setCustomSnapTarget('ingrassatore', 'tappino_grasso_dx_original', new THREE.Vector3(0.1,0,0))

🎬 Sistema Animazioni - Traslazioni a Posizioni Originali

L'AnimationSystem è stato esteso per supportare riferimenti _original nelle traslazioni.

Implementazione:

• File: js/core/AnimationSystem.js • Funzione: parseMovementOperation() - Rileva suffisso _original • Funzione: executeMultiStepMovement() - Usa Scene3D.findModelByName() per riferimenti originali • Supporto: Traslazione assoluta verso posizioni iniziali di altri modelli

Sintassi Tutorial:

Traslazione relativa (esistente):
Azione1=traslazione:(-0.2,0,0,0.8)

Traslazione verso elemento corrente:
Azione1=traslazione:tappino_grasso_dx,(0.1,0,0,0.8)

Traslazione verso posizione originale (NUOVO):
Azione1=traslazione:tappino_grasso_dx_original,(0.1,0,0,0.8)

Output Console Esempio:

🎯 TRANSLATION: To ORIGINAL position of "tappino_grasso_dx_original" with offset (0.1, 0, 0) duration 0.8s 🎯 ORIGINAL REF: Found original position for "tappino_grasso_dx_original": (1.500, 0.200, -0.500) 🎯 ALIGNMENT DEBUG: Calculated final position: (1.600, 0.200, -0.500)

🔄 Sistema Drag & Drop - Snap a Posizioni Originali

Il DragDropSystem supporta ora snap personalizzati verso posizioni originali di altri oggetti.

Implementazione:

• File: js/core/DragDropSystem.js • Struttura: customSnapTargets Map per memorizzare configurazioni • Funzione: findSnapTarget() - Controlla prima target personalizzati, poi posizione originale oggetto • API: setCustomSnapTarget(), removeCustomSnapTarget(), getCustomSnapTargets()

API Pubbliche:

setCustomSnapTarget(objectName, targetName, offset)
Imposta dove deve snappare un oggetto quando trascinato
removeCustomSnapTarget(objectName)
Rimuove snap personalizzato (torna al comportamento standard)
getCustomSnapTargets()
Ottiene tutte le configurazioni snap personalizzate

Esempi d'uso:

Snap alla posizione corrente di un altro oggetto:
DragDropSystem.setCustomSnapTarget('ingrassatore', 'tappino_rosso')

Snap alla posizione originale di un altro oggetto:
DragDropSystem.setCustomSnapTarget('ingrassatore', 'tappino_grasso_dx_original')

Snap con offset personalizzato:
DragDropSystem.setCustomSnapTarget('ingrassatore', 'tappino_grasso_dx_original', new THREE.Vector3(0.1, 0, 0))

🔧 Sistema Core - Scene3D findModelByName Esteso

Il sistema core Scene3D è stato esteso per gestire riferimenti virtuali alle posizioni originali.

Implementazione:

• File: js/scene3d-modular.js • Funzione: findModelByName() - Rileva suffisso _original automaticamente • Funzione: createOriginalPositionReference() - Crea oggetti virtuali con posizioni originali • Sistema: Calcoli bounding box mantenuti per compatibilità

Comportamento:

Ricerca standard: Scene3D.findModelByName('filtro') → oggetto reale corrente
Ricerca originale: Scene3D.findModelByName('filtro_original') → oggetto virtuale con posizione iniziale

✅ Scenari d'Uso

1. Assemblaggio Sequenziale

L'ingrassatore deve tornare alla posizione originale del tappino dopo essere stato spostato:
Azione1=traslazione:tappino_grasso_dx_original,(0,0,0,0.8)

2. Reset Posizioni

Riporta tutti i componenti alle posizioni iniziali per ricominciare assemblaggio:
Azione1=traslazione:filtro_original,(0,0,0,1.0)
Azione2=traslazione:ingrassatore_original,(0,0,0,1.0)

3. Drag & Drop Guidato

L'utente trascina componenti che devono snappare alle posizioni originali:
DragDropSystem.setCustomSnapTarget('vite1', 'sede_vite1_original')
