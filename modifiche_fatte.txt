  🚀 Come Usare

  Per aggiungere tool custom a uno scenario:

  1. Crea/modifica scenes/TuoScenario/config.txt:
  [Tools]
  Tool=nuovo_tool

  [Tool:nuovo_tool]
  Label=Nuovo Tool
  Icon=utilimages/nuovo_tool.png
  Cursor=cursors/nuovo_tool_normal.svg
  CursorPressed=cursors/nuovo_tool_frame1.svg
  CursorPressedFrame2=cursors/nuovo_tool_frame2.svg
  CursorHotspotX=10
  CursorHotspotY=15
  Type=tool
  TutorialNames=NuovoTool,tool_custom
  2. Aggiungi in home_config.txt:
  [TuoScenario]
  Scenario=scenes/TuoScenario
  Tutorial=scenes/TuoScenario/tutorial.txt
  Configuration=scenes/TuoScenario/config.txt
  3. Usa in tutorial:
  [Step X]
  Utensile=NuovoTool
  4. Il sistema gestisce automaticamente:
    - Caricamento config
    - Generazione CSS cursori animati
    - UI legenda tool
    - Mapping Utensile= → tool ID
