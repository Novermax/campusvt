🖱️ PARTE 1: Controlli Camera e Mouse

Sistema di Navigazione 3D Professionale

Campus Virtual Training utilizza un sistema di controlli camera intuitivo simile ai software CAD professionali. Ogni azione del mouse ha una funzione specifica per l'esplorazione tridimensionale.

🖱️ Click Sinistro

Funzione: Selezione Oggetti Tutorial

Seleziona componenti durante i tutorial per eseguire azioni e avanzare negli step.

🖱️ Click Destro + Trascinamento

Funzione: Rotazione Orbitale

Ruota la camera attorno al punto pivot corrente per osservare i modelli da ogni angolazione.

🖱️ Rotella di Scorrimento

Funzione: Zoom Avanti/Indietro

Avvicina o allontana la camera dal punto pivot per dettagli o visione d'insieme.

🖱️ Click Pulsante Centrale

Funzione: Pivot Dinamico

Imposta nuovo punto pivot sull'oggetto cliccato con animazione fluida verso il nuovo centro di rotazione.

Controlli Base 3D

💡 Scenario Tipico: Ispezione Filtro Pompa

  1. Orientamento Iniziale: La camera si posiziona automaticamente per inquadrare tutti i componenti
  2. Rotazione Esplorativa: Click destro + trascinamento per ruotare attorno alla pompa
  3. Focus sul Filtro: Click pulsante centrale sul filtro per renderlo il nuovo pivot
  4. Zoom di Dettaglio: Rotella in avanti per avvicinarsi e osservare i dettagli

Sistema Pivot Dinamico

Il sistema pivot dinamico è una funzionalità avanzata che permette di cambiare istantaneamente il centro di rotazione della camera.

🎯 Che cos'è il Pivot Point?

Il pivot point è il punto attorno al quale ruota la telecamera. Per default è il centro della scena, ma può essere cambiato cliccando su qualsiasi oggetto con il pulsante centrale del mouse.

Funzionamento del Pivot Dinamico:

  • Rilevamento Oggetto: Sistema raycasting identifica l'oggetto sotto il cursore
  • Calcolo Centro: Determina automaticamente il centro del bounding box dell'oggetto
  • Animazione Fluida: Camera si muove dolcemente verso il nuovo pivot (durata: 0.8s)
  • Mantenimento Distanza: Preserva la distanza relativa dal pivot precedente
  • Orientamento Automatico: Camera rimane sempre orientata verso il pivot

⚙️ PARTE 3: Configurazione Scenari

File di Configurazione

Il sistema utilizza due livelli di configurazione gerarchici per massima flessibilità:

🗂️ Schema Configurazione

  1. home_config.txt → Definisce gli scenari disponibili nel menu principale
  2. tutorial.txt → Definisce i passi specifici di ogni scenario

Struttura home_config.txt (REALE):

Il file home_config.txt è il cuore della configurazione del sistema: definisce tutti gli scenari disponibili nel menu principale e le loro caratteristiche. Ogni sezione tra parentesi quadre rappresenta uno scenario diverso che apparirà come card selezionabile nell'interfaccia.

📋 Funzioni dei Parametri Principali

  • CameraPos: Posizione iniziale della camera 3D quando si carica lo scenario (coordinate X,Y,Z)
  • CameraTarget: Punto verso cui la camera guarda inizialmente (centro di interesse)
  • AmbientLight: Illuminazione ambientale diffusa (colore esadecimale, intensità)
  • DirectionalLight: Luce direzionale principale (colore, intensità, posizione sorgente)
  • description_key: Chiave per recuperare la descrizione dello scenario da file di localizzazione
  • image: Percorso dell'immagine anteprima mostrata nella card dello scenario
  • tutorial: Percorso del file tutorial.txt con i passi specifici dello scenario
  • model: Modelli 3D da caricare (può essere ripetuto per modelli multipli)
  • direction: Direzione di movimento predefinita per ogni modello (X,Y,Z)

Flusso di utilizzo: All'avvio, il sistema legge questo file, crea le card nel menu per ogni scenario [Nome Scenario], e quando l'utente seleziona una card, carica i modelli specificati, posiziona la camera secondo CameraPos/CameraTarget, applica l'illuminazione configurata e rende disponibile il tutorial.txt associato.

[TEST] CameraPos=(-1.5, 0.5,-0.2) CameraTarget=(0, 0, 0) AmbientLight=0x404040,1.5 DirectionalLight=0xffffff,2.5,(-8, 15, 10) description_key=scenario_test_description image=menuimages/1.png tutorial=scenes/Test/tutorial.txt model=models/tappino_grasso_dx.glb direction=-1,0,0 [Manutenzione pompa del vuoto] CameraPos=(-1.5, 0.5,-0.2) CameraTarget=(0, 0, 0) description_key=scenario_pump_maintenance_description image=menuimages/pompavuoto.png tutorial=scenes/Pompa_Becker/tutorial.txt model=models/culatta.glb direction=0,0,1

⚠️ Convenzioni di Naming

  • Nomi scenario senza caratteri speciali o spazi nelle cartelle
  • File modelli con estensioni supportate: .glb, .gltf, .obj, .stl
  • Immagini preview in formato .jpg o .png
  • Descrizioni brevi ma informative (max 100 caratteri)

📐 Sistema Coordinate 3D

Prima di iniziare qualsiasi configurazione scenari, è fondamentale comprendere l'orientamento dello spazio tridimensionale:

📍 SISTEMA COORDINATE CAMPUS VIRTUAL TRAINING: ✅ X: Orizzontale Destra-Sinistra • Valori Positivi (+X): Verso DESTRA • Valori Negativi (-X): Verso SINISTRA ✅ Y: Verticale Alto-Basso • Valori Positivi (+Y): Verso l'ALTO • Valori Negativi (-Y): Verso il BASSO (sotto pavimento) ✅ Z: Profondità Avanti-Indietro • Valori Positivi (+Z): Verso di TE (fuori schermo) • Valori Negativi (-Z): Lontano da te (dentro schermo)

Durante la configurazione di scenari e posizionamenti:

  • Definire posizioni camera (CameraPos) e target (CameraTarget)
  • Posizionare modelli con direttive Posizione= e Rotazione=
  • Interpretare coordinate nei file di configurazione
  • Impostare direzioni di movimento per animazioni

📖 PARTE 4: Creazione Tutorial Base

Sintassi Fondamentale

I file tutorial.txt utilizzano una sintassi INI-like semplice e intuitiva:

# Configurazione globale scenario (opzionale) CameraPos=(-1.5, 0.5, -0.2) CameraTarget=(0, 0, 0) CameraZoom=1.2 [Nome Tutorial] CameraPos=(-1.5, 0.8, -0.5) # Override camera per questo tutorial [Step 1 - Rimozione Coperchio] Elemento=models/coperchio.glb Descrizione=Rimuovi il coperchio superiore della pompa CameraPos=(0.5, 1.2, 1.8) CameraTarget=coperchio CameraTransitionTime=2.0 Utensile=ChiaveInglese Azione1=svita Distanza=0.8 [Step 2 - Estrazione Filtro] Elemento=models/filtro.glb Descrizione=Estrai delicatamente il filtro dalla sede Utensile=Mani Azione1=estrai Distanza=1.2

Elementi Sintassi:

Elemento Funzione Obbligatorio
[Nome Tutorial] Definisce un nuovo tutorial/capitolo Sì
[Step N - Descrizione] Definisce un passo del tutorial Sì
Elemento= Modello 3D interessato dall'azione Sì
Descrizione= Testo mostrato all'utente Sì
Utensile= Tool richiesto per l'operazione No
Azione1= Animazione da eseguire No

Parametri degli Step

Controllo Camera:

CameraPos=(-1.5, 0.8, -0.5) # Posizione assoluta camera CameraPos=ingrassatore:(-1, 0, 0) # Posizione relativa a oggetto CameraTarget=(0, 0, 0) # Punto target coordinate CameraTarget=filtro # Target su oggetto (centro bounding box) CameraZoom=2.2 # Fattore zoom (1.0 = default) CameraTransitionTime=1.5 # Durata movimento camera (secondi)

Utensili Disponibili:

  • Mano: Operazioni manuali, presa diretta
  • Chiave Inglese: Chiave regolabile per dadi e bulloni
  • Brugola: Chiave esagonale per viti brugola
  • Aria: Pistola aria compressa con effetti particellari realistici

💡 Esempio Step Completo

[Step 3 - Pulizia Filtro] Elemento=models/filtro.glb Descrizione=Pulisci il filtro con aria compressa per rimuovere depositi e polvere CameraPos=(-0.2, 0.33, 0.74) CameraTarget=filtro CameraZoom=0.5 CameraTransitionTime=2.5 Utensile=Aria Azione1=traslazione:(0, 0.01, 0, 0.5) Azione2=appoggia(0.5)

Cosa succede:

  1. Camera si posiziona per inquadrare il filtro con transizione fluida
  2. UI richiede selezione tool "Aria" dalla barra strumenti
  3. Utente clicca sul filtro → Effetto particellare realistico
  4. Filtro si solleva leggermente, poi si appoggia automaticamente
  5. Tutorial avanza al step successivo

🎬 PARTE 5: Sistema Animazioni

Tipi di Animazioni

Il sistema supporta diversi tipi di animazioni per simulare realisticamente le operazioni meccaniche:

Tipo Sintassi Uso Tipico
estrai Azione1=estrai Rimozione coperchi, filtri
inserisci Azione1=inserisci Installazione componenti
svita Azione1=svita Rotazione + traslazione viti
avvita Azione1=avvita Serraggio componenti
traslazione Azione1=traslazione:(x,y,z,durata) Movimento lineare personalizzato
rotazione Azione1=rotazione:(x,y,z,durata) Rotazione su coordinate specifiche
appoggia Azione1=appoggia(durata) Posizionamento automatico a Y=0

🔧 Esempio Smontaggio Complesso

[Step 5 - Svitamento Vite Principale] Elemento=models/vite_principale.glb Descrizione=Svita la vite principale in senso antiorario con chiave esagonale Utensile=ChiaveBrugola Azione1=rotazione:(0,0,-360,2.0);traslazione:(0,0.6,0,2.0) Distanza=0.8 # Azione combinata: # - Rotazione -360° (6 giri antiorario) in 2 secondi # - Traslazione simultanea verso l'alto di 0.6 unità # - Distanza estrazione totale: 0.8 unità

🆕 Riferimenti Posizioni Originali

Il sistema _original permette di riferirsi alle posizioni iniziali dei modelli per operazioni di reset e assemblaggio avanzato:

# Traslazione normale (relativa alla posizione corrente) Azione1=traslazione:(-0.2,0,0,0.8) # Traslazione verso posizione corrente di altro oggetto Azione1=traslazione:tappino_grasso_dx,(0.1,0,0,0.8) # Traslazione verso POSIZIONE ORIGINALE di altro oggetto (NUOVO) Azione1=traslazione:tappino_grasso_dx_original,(0.1,0,0,0.8)

Casi d'Uso Tipici:

🔄 Reset Componenti

Scenario: Ripristinare un componente alla sua posizione iniziale dopo spostamenti o animazioni

# Riporta filtro alla posizione iniziale Azione1=traslazione:filtro_original,(0,0,0,1.0)

Applicazione: Ideale per permettere all'utente di "ricominciare" un'operazione senza ricaricare l'intero scenario.

⚙️ Assemblaggio Sequenziale

Scenario: Posizionare componenti in sedi originali di altri oggetti per simulare sostituzioni o assemblaggi

# Ingrassatore torna alla sede originale del tappino Azione2=traslazione:tappino_grasso_dx_original,(0,0,0,1.0)

Applicazione: Perfetto per training di sostituzione componenti dove un pezzo deve occupare la posizione esatta di un altro.

🔁 Reset Completo Scenario

Scenario: Ripristinare tutti i componenti alle posizioni iniziali per ricominciare completamente il tutorial

# Reset multiplo per ricominciare tutorial Azione1=traslazione:filtro_original,(0,0,0,1.0) Azione2=traslazione:ingrassatore_original,(0,0,0,1.5) Azione3=traslazione:coperchio_original,(0,0,0,2.0)

Applicazione: Utile per creare un pulsante o step di "reset generale" che riporta tutto allo stato iniziale per ripetere il training.

🎯 Funzionamento Sistema _original

  • Memorizzazione Automatica: Posizioni iniziali salvate al caricamento
  • Riferimenti Virtuali: Oggetti _original calcolati dinamicamente
  • Performance Ottimizzate: Zero overhead se non utilizzato
  • Backward Compatible: Tutorial esistenti continuano a funzionare

🔄 PARTE 6: Sistema Drag & Drop per Assemblaggio Meccanico

🎯 IL CUORE DELL'APPLICAZIONE

Il sistema Drag & Drop rappresenta la funzionalità più importante di Campus Virtual Training: permette ai tecnici di apprendere l'assemblaggio di parti meccaniche attraverso manipolazione diretta 3D, simulando fedelmente le operazioni reali di montaggio industriale.

Perché è fondamentale:

  • Apprendimento Cinestetico: I tecnici "sentono" il processo di assemblaggio
  • Memoria Muscolare: Sviluppo di automatismi per operazioni reali
  • Comprensione Spaziale: Visualizzazione tridimensionale delle relazioni tra componenti
  • Training Sicuro: Errori di assemblaggio senza conseguenze su macchinari reali
  • Standardizzazione: Procedure uniformi per tutti i tecnici

Assemblaggio di Parti Meccaniche - Configurazione

Il sistema Drag & Drop trasforma l'apprendimento teorico in esperienza pratica di assemblaggio meccanico:

[Step 8 - Assemblaggio Interattivo] Elemento=models/ingrassatore.glb Descrizione=Trascina l'ingrassatore nella posizione corretta per l'installazione DragDrop=true # Abilita trascinamento DragDropObjects=ingrassatore # Lista oggetti draggabili DragDropDistance=1.2 # Distanza snap automatico Utensile=Mani

Parametri Drag & Drop:

Parametro Descrizione Valori
DragDrop Abilita/disabilita sistema true/false
DragDropObjects Lista oggetti trascinabili nomi separati da virgola
DragDropDistance Distanza per snap automatico 0.5 - 3.0 (unità 3D)

🆕 Snap Personalizzati con _original

Configurazione avanzata tramite console per snap a posizioni specifiche:

// Snap standard - oggetto torna alla propria posizione originale DragDropSystem.enable(['ingrassatore']) // Snap personalizzato - oggetto snappe alla posizione corrente di altro oggetto DragDropSystem.setCustomSnapTarget('ingrassatore', 'tappino_rosso') // Snap a posizione ORIGINALE di altro oggetto (NUOVO) DragDropSystem.setCustomSnapTarget('ingrassatore', 'tappino_grasso_dx_original') // Snap con offset preciso dalla posizione target DragDropSystem.setCustomSnapTarget('ingrassatore', 'filtro_original', new THREE.Vector3(0.1, 0, 0))

Workflow Completo Drag & Drop:

  1. Progettazione Posizioni: Definire dove ogni componente deve essere posizionato
  2. Export Posizioni: Scene3D.exportCurrentModelPositions() dalla console
  3. Salvataggio Coordinate: Copiare output nel tutorial.txt per posizionamento automatico
  4. Configurazione Snap: Impostare target personalizzati per training drag & drop
  5. Test Scenario: Verificare comportamento trascinando componenti

🔧 Esempio Concreto: Assemblaggio Pompa del Vuoto

Scenario Reale: Un tecnico deve assemblare una pompa industriale Becker dopo manutenzione

// Setup assemblaggio pompa industriale - Sequenza realistica DragDropSystem.enable(['filtro', 'ingrassatore', 'coperchio', 'vite_1', 'vite_2']) // 1. FILTRO: deve tornare esattamente nella sede originale DragDropSystem.setCustomSnapTarget('filtro', 'sede_filtro_original') // 2. INGRASSATORE: posizione precisa sul tappino grasso con offset millimetrico DragDropSystem.setCustomSnapTarget('ingrassatore', 'tappino_grasso_dx_original', new THREE.Vector3(0.05, 0, 0)) // Offset di 5cm per accoppiamento // 3. COPERCHIO: chiusura ermetica sulla flangia DragDropSystem.setCustomSnapTarget('coperchio', 'flangia_coperchio_original') // 4. VITI: serraggio in sequenza incrociata (come procedure reali) DragDropSystem.setCustomSnapTarget('vite_1', 'sede_vite_1_original') DragDropSystem.setCustomSnapTarget('vite_2', 'sede_vite_2_original')

Risultato: Il tecnico impara la sequenza corretta di assemblaggio, le tolleranze di accoppiamento e sviluppa la precisione necessaria per operazioni reali, tutto in ambiente sicuro senza rischio di danneggiare costosi macchinari industriali.

🏗️ PARTE 6.5: Sistema Assemblaggio Sequenziale Avanzato

🚀 NUOVA FUNZIONALITÀ PROFESSIONALE

Il Sistema Assemblaggio Sequenziale rappresenta l'evoluzione del sistema Drag & Drop per scenari industriali complessi che richiedono:

  • Sequenze Obbligatorie: Componenti montabili solo in ordine specifico
  • Insiemi Intercambiabili: Gruppi con ordine libero interno (viti, manopole)
  • Validazione Dipendenze: Controllo automatico prerequisiti
  • Punti Aggancio Multipli: Posizioni alternative per stesso componente
  • Feedback Visivo Avanzato: Stati assemblaggio colorati

Concetti Fondamentali

🔢 Sequenze Obbligatorie

Definiscono l'ordine VINCOLANTE di assemblaggio per rispettare procedure industriali certificate.

1. Base pompa (sempre disponibile) 2. Filtro (richiede base) 3. Coperchio (richiede base + filtro) 4. Viti coperchio (richiede coperchio)

🔄 Insiemi Intercambiabili

Gruppi di componenti montabili in qualsiasi ordine interno al gruppo.

• Gruppo Viti: vite_1, vite_2, vite_3, vite_4 • Gruppo Tappini: tappino_dx, tappino_sx • Gruppo Manopole: manopola_A, manopola_B

📍 Punti Aggancio Multipli

Ogni componente può avere più posizioni di montaggio alternative per flessibilità assemblaggio.

✓ Slot alternativi per componenti simili ✓ Tolleranze realistiche accoppiamenti ✓ Configurazioni multiple assemblaggio

Configurazione JSON Assembly

Il sistema utilizza file JSON per definire completamente logica di assemblaggio:

Percorso: assembly_configs/pompa_becker_reale.json

{ "metadata": { "version": "1.0", "description": "Assemblaggio Pompa Becker con modelli reali", "scenario": "Pompa_Becker" }, "sequence": [ "base_assembly", "filtro_assembly", "coperchio_assembly", "viti_coperchio_assembly", "tappini_assembly", "ingrassatori_assembly" ], "snapPoints": { "filtro": { "nodeId": "filtro_assembly", "positions": [ { "id": "snap_filtro_sede", "position": [0, 0.1, 0], "rotation": [0, 0, 0] } ] } }, "interchangeableNodes": { "viti_coperchio_assembly": [ "vite_coperchio_1", "vite_coperchio_2", "vite_coperchio_3", "vite_coperchio_4" ] }, "dependencies": { "filtro_assembly": ["base_assembly"], "coperchio_assembly": ["base_assembly", "filtro_assembly"], "viti_coperchio_assembly": ["coperchio_assembly"] } }

Sezioni Configurazione:

Sezione Funzione Descrizione
sequence Ordine Assemblaggio Array con sequenza OBBLIGATORIA di step
snapPoints Posizioni Montaggio Coordinate precise con posizioni multiple alternative
interchangeableNodes Gruppi Intercambiabili Definisce insiemi con ordine libero interno
dependencies Prerequisiti Lista dipendenze per validazione assemblaggio

Integrazione Tutorial System

Configurazione nel file tutorial.txt per abilitare assemblaggio sequenziale:

[Step 1 - Assemblaggio Sequenziale Guidato] Elemento=models/filtro.glb Descrizione=Inizia assemblaggio seguendo sequenza corretta. Prima inserisci il filtro. Utensile=Mani # Configurazione assemblaggio AssemblyMode=true AssemblyConfig=assembly_configs/pompa_becker_reale.json CurrentStep=filtro_assembly # Controllo componenti AllowedComponents=filtro MinimumRequired=1 InterchangeableNode=filtro_assembly # Feedback visivo DragDropDistance=0.3 ShowSnapPoints=filtro ValidateAssembly=true UndoEnabled=true

Parametri Specifici Assembly:

Parametro Funzione Valori

AssemblyConfig File configurazione JSON Percorso relativo

AllowedComponents Componenti montabili Lista separata da virgola
InterchangeableNode Nodo intercambiabile attivo Nome nodo da JSON

MinimumRequired Numero minimo componenti Numero intero
UndoEnabled Sistema undo step true/false

Comportamenti Sistema

🎨 Feedback Visivo Stati Assemblaggio

🟢 Verde - Montabile

Componente può essere montato (prerequisiti soddisfatti)

🔴 Rosso - Bloccato

Componente non montabile (prerequisiti mancanti)

🔵 Blu - Montato

Componente già montato correttamente

🟡 Giallo - In Corso

Componente in fase di montaggio (drag attivo)

Sequenza Validazione Automatica:

  1. Check Prerequisiti: Verifica dipendenze step corrente in sequence
  2. Check Componente: Verifica se componente è in AllowedComponents
  3. Check Nodo: Se nodo intercambiabile, verifica slot disponibili
  4. Check Posizione: Verifica snap point disponibile e compatibile
  5. Montaggio: Esegue snap automatico con animazione fluida

⚙️ Gestione Errori Assemblaggio

  • Assemblaggio Fuori Sequenza: "Prerequisiti mancanti per questo step"
  • Componente Non Permesso: "Componente non montabile in questo step"
  • Slot Occupato: Cerca automaticamente slot alternativo disponibile
  • Nodo Incompleto: Mostra progresso "X/Y componenti montati"

Esempio Completo: Riassemblaggio Pompa Becker

Scenario Reale: Tutorial configurato nel file scenes/Pompa_Becker/tutorial.txt sezione [Riassemblaggio]

🏭 Flusso Assemblaggio Industriale

  1. Step 1 - Filtro: Solo filtro montabile (sequenza obbligatoria)
  2. Step 2 - Coperchio: Filtro montato → Coperchio diventa verde
  3. Step 3 - Viti Coperchio: 4 viti in qualsiasi ordine (insieme intercambiabile)
  4. Step 4 - Tappini: Tappini dx/sx ordine libero (insieme intercambiabile)
  5. Step 5 - Ingrassatore: Posizionamento finale (richiede tutti i prerequisiti)
  6. Completamento: Sistema congratulazioni + reset disponibile

🏠 PARTE 6.7: Sistema Reset Posizioni Scenario Originali

🚀 RISOLUZIONE PROBLEMA FONDAMENTALE

Il Sistema Reset Posizioni Scenario risolve definitivamente il problema del reset tra tutorial: ora quando cambi tutorial, tutti i modelli tornano esattamente alle posizioni di caricamento dello scenario, poi applicano le impostazioni specifiche del nuovo tutorial.

  • Doppio Salvataggio: Posizioni scenario pure + posizioni tutorial personalizzate
  • Reset Intelligente: Scenario originale → Applica impostazioni tutorial
  • Zero Confusione: Ogni tutorial inizia sempre da stato pulito
  • Backward Compatible: Tutorial esistenti continuano a funzionare

Problema Risolto

❌ PRIMA: Problema Reset Tutorial

Scenario tipico problematico:

  1. Tutorial "Riassemblaggio": Modelli spostati durante training
  2. Cambio a "Pulizia filtro": Modelli rimanevano nelle posizioni del tutorial precedente
  3. Confusione Utente: Tutorial iniziava con setup sbagliato
  4. Necessità Reload: Costretto a ricaricare intero scenario

✅ DOPO: Reset Intelligente

Comportamento corretto implementato:

  1. Salvataggio Automatico: Posizioni pure memorizzate al caricamento scenario
  2. Reset a Scenario: Tutti i modelli tornano alle posizioni di caricamento
  3. Applicazione Tutorial: Impostazioni specifiche applicate sopra posizioni pulite
  4. Tutorial Pronto: Stato perfetto per iniziare nuovo training

Architettura Sistema

Doppio Sistema di Memorizzazione:

Tipo Posizioni Quando Salvate Quando Usate Modificabili
🏠 Scenario Originali Solo al caricamento scenario Reset tra tutorial ❌ Immutabili
📝 Tutorial Correnti Ad ogni cambio tutorial Reset interno tutorial ✅ Aggiornabili
🏗️ STRUTTURE DATI SISTEMA: // Posizioni pure scenario (immutabili) scenarioOriginalPositions: new Map() // UUID → {position, rotation, scale} // Posizioni tutorial corrente (modificabili) initialModelPositions: new Map() // UUID → {position, rotation, scale}

Funzionamento Automatico

Sequenza Reset Cambio Tutorial:

  1. Click Nuovo Tutorial: Utente seleziona tutorial diverso dal menu
  2. Reset Scenario: Scene3D.resetAllModelsToScenarioPositions() eseguito automaticamente
  3. Posizioni Pure: Tutti i modelli tornano alle coordinate di caricamento scenario
  4. Applicazione Tutorial: Impostazioni specifiche tutorial (Posizione=, Rotazione=) applicate sopra
  5. Tutorial Pronto: Stato perfetto per iniziare training

🎯 Vantaggi UX

  • Prevedibilità: Ogni tutorial inizia sempre dallo stesso stato
  • Pulizia: Nessuna "contaminazione" tra tutorial diversi
  • Velocità: Reset automatico senza intervento utente
  • Affidabilità: Sistema robusto senza possibilità di stati inconsistenti

Risoluzione Problemi Comuni

❌ Problema: "Orientamento sbagliato assemblaggio"

Soluzione:

  1. Verifica orientamento camera: Scene3D.getCameraInfo()
  2. Ricorda sistema coordinate: +X=destra, +Y=alto, +Z=verso di te
  3. Usa click pulsante centrale mouse per pivot fluido

❌ Problema: "Coordinate sbagliate nei tutorial"

Soluzione:

  1. Export posizioni correnti: Scene3D.exportCurrentModelPositions()
  2. Copia valori esatti nel tutorial.txt
  3. Ricorda sistema coordinate: +X=destra, +Y=alto, +Z=verso di te

🎯 Sistema SnapPoint (Coordinate Arbitrarie)

📋 Panoramica

Sistema per definire punti di snap a coordinate (x,y,z) arbitrarie nello spazio 3D.

  • Coordinate Dirette: Specifica esattamente dove deve snappare l'oggetto
  • Multi-oggetto: Configurazione simultanea di più oggetti
  • Priorità Alta: Prevale su riferimenti _original e posizioni salvate

Sintassi

# Sintassi base (singolo oggetto) SnapPoint=oggetto:(x,y,z) # Esempio SnapPoint=filtro:(0.5,0.2,0.3) # Multi-oggetto (separatore ;) SnapPoint=filtro:(0.5,0.2,0.3);vite_1:(-0.1,0,0.5);vite_2:(0.1,0,0.5)
🔧 Esempio Pratico: Riposizionamento Filtro
[Step 10 - Posiziona Filtro Custom] DragDrop=true DragDropObjects=filtro DragDropDistance=0.3 SnapPoint=filtro:(0.5,0.2,0.3) Utensile=Mani Descrizione=Posiziona il filtro nella posizione personalizzata

Comportamento: Il filtro snapperà esattamente alle coordinate (0.5, 0.2, 0.3) quando trascinato entro 0.3 unità.

⚠️ Note Importanti

  • Sistema Coordinate: +X destra, +Y alto, +Z verso di te
  • Snap Centro BB: Usa centro bounding box oggetto, non pivot
  • Validazione: Coordinate non numeriche vengono ignorate con warning

Comandi Console Debug

// Imposta snap a coordinate dirette DragDropSystem.setCustomSnapPosition('filtro', 0.5, 0.2, 0.3) // Verifica stato snap DragDropSystem.debugSnapSystem() // Export posizioni correnti per ottenere coordinate Scene3D.exportCurrentModelPositions()

🔄 Sistema SnapTargets (Multipli Intercambiabili)

📋 Panoramica

Sistema per permettere a più oggetti di fare snap su posizioni originali di ALTRI oggetti in modo intercambiabile.

  • Caso d'Uso: 2+ viti possono essere montate su 2+ fori, indipendentemente dall'ordine
  • Algoritmo Intelligente: Trova automaticamente il target più vicino
  • Snap Centro BB: Usa centro bounding box target, non pivot

Sintassi

# Sintassi base (singolo oggetto) SnapTargets=oggetto:target1_original,target2_original # Esempio: 1 vite su 2 fori intercambiabili SnapTargets=vite_A:foro_1_original,foro_2_original # Multi-oggetto (separatore ;) SnapTargets=vite_A:foro_1_original,foro_2_original;vite_B:foro_1_original,foro_2_original
🔩 Esempio Semplice: 2 Viti su 2 Fori
[Step 14 - Inserisci Viti Estrattore] DragDrop=true DragDropObjects=vite_culatta_1,vite_culatta_2 DragDropDistance=0.1 SnapTargets=vite_culatta_1:estrattoresx_original,estrattoredx_original;vite_culatta_2:estrattoresx_original,estrattoredx_original Utensile=Mani Descrizione=Inserisci le viti negli estrattori (ordine libero)

Comportamento: Entrambe le viti possono snappare su entrambi gli estrattori. Il sistema sceglie automaticamente il più vicino.

🔧 Esempio Complesso: 4 Viti su 4 Fori
[Step 20 - Viti Intercambiabili] DragDrop=true DragDropObjects=vite_1,vite_2,vite_3,vite_4 DragDropDistance=0.2 SnapTargets=vite_1:foro_A_original,foro_B_original,foro_C_original,foro_D_original;vite_2:foro_A_original,foro_B_original,foro_C_original,foro_D_original;vite_3:foro_A_original,foro_B_original,foro_C_original,foro_D_original;vite_4:foro_A_original,foro_B_original,foro_C_original,foro_D_original Utensile=Mani

Comportamento: Tutte e 4 le viti possono andare su tutti e 4 i fori, ordine completamente libero.

⚖️ Esempio Asimmetrico: Vincoli Diversi
SnapTargets=vite_A:foro_1_original,foro_2_original;vite_B:foro_1_original,foro_2_original,foro_3_original

Comportamento: vite_A solo su foro_1/foro_2, vite_B su tutti e 3 i fori.

💡 Log Debug Console

[DragDropSystem] 🔄 Verifica 2 snap targets intercambiabili per "vite_A" [DragDropSystem] 📏 Target 1/2: "foro_1_original" - Distanza: 0.234 [DragDropSystem] 📏 Target 2/2: "foro_2_original" - Distanza: 0.512 [DragDropSystem] ⭐ Nuovo target più vicino: "foro_1_original" a distanza 0.234 [DragDropSystem] 🧲 Snap intercambiabile disponibile

⚠️ Differenza SnapPoint vs SnapTargets

  • SnapPoint: Usa coordinate (x,y,z) dirette
  • SnapTargets: Usa NOMI di oggetti con suffisso _original
  • Priorità: Multi-target > coordinate dirette > singolo target > posizione originale

📏 Sistema Distanza Configurabile Comandi Movimento

📋 Panoramica

Sistema per personalizzare la distanza di traslazione dei comandi svita, avvita, estrai, inserisci.

  • Sintassi Opzionale: Parametro distanza tra parentesi
  • Backward Compatible: Sintassi senza parametro usa distanze default
  • Validazione: Valori negativi o non numerici → warning + fallback a default

Valori Default

Comando Distanza Default Sintassi Personalizzata
svita 0.5 unità svita(0.8)
avvita 0.5 unità avvita(1.2)
estrai 0.4 unità estrai(0.6)
inserisci 0.4 unità inserisci(0.3)
🔩 Esempio: Svitamento con Estrazione Maggiorata
[Step 1 - Rimuovi Vite con Estrazione Lunga] Elemento=models/vite_culatta_1.glb Utensile=ChiaveBrugola Azione1=svita(0.8) # Estrae di 0.8 unità (default sarebbe 0.5) Azione2=traslazione:(-0.1,0,0,0.2) Azione3=appoggia(0.2) Descrizione=Svita vite con estrazione maggiorata

Comportamento: Ruota 5 giri (1800°) ed estrae di 0.8 unità lungo direction configurato in home_config.txt

🔧 Confronto Sintassi
# Sintassi classica (usa default 0.5) Azione1=svita # Sintassi personalizzata (usa 0.8) Azione1=svita(0.8) # Entrambe ruotano 5 giri (1800°) # Ma estraggono distanze diverse

💡 Come Funziona

  1. Direction da home_config.txt: Legge il vettore direction del modello
  2. Calcolo Traslazione: distanza × vettore direction
  3. Esempio: svita(0.8) con direction=0,0,1 → traslazione (0, 0, 0.8)

⚠️ Configurazione home_config.txt

Il vettore direction deve essere configurato per ogni modello che usa svita/avvita/estrai/inserisci:

model=models/vite_culatta_1.glb direction=0,0,1 # Direzione asse Z positivo
