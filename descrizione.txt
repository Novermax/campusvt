  Sistema di formazione virtuale 3D per training tecnico/industriale con visualizzazione interattiva di componenti
  meccanici.

  Caratteristiche Principali

  Tecnologia

  - Three.js per rendering 3D WebGL
  - Architettura modulare ES6 con import/export
  - Supporto formati 3D: OBJ, MTL, STL, GLB/GLTF
  - CSS modulare organizzato in componenti

  Funzionalità Core

  1. Sistema di autenticazione con credenziali e scadenza utenti
  2. Visualizzatore 3D interattivo con controlli camera avanzati
  3. Caricamento scenari automatico da cartelle server
  4. Tutorial guidati con sistema step-by-step
  5. Modalità manuale per esplorazione libera

  Componenti Tecnici

  - Pompe industriali (Becker) con parti smontabili
  - Strumenti di lavoro (chiavi, martelli, brugole)
  - Sistema di animazioni per movimenti componenti
  - Legenda strumenti contestuale

  Caratteristiche Specifiche

  - Blocco dispositivi mobili (solo desktop supportato)
  - Progress bar per caricamento modelli
  - Sistema di tutorial con fumetti informativi
  - Auto-fit e zoom automatico sui modelli
  - Controlli mouse avanzati (pan, rotate, zoom)

  Target

  Sistema di formazione per tecnici industriali su manutenzione e assemblaggio di pompe del vuoto e apparecchiature
  meccaniche complesse.

  Questa è una soluzione B2B specializzata per training tecnico industriale con focus sulla formazione pratica
  attraverso simulazioni 3D realistiche.
