🖐️ HoldableSystem - Oggetti Impugnabili

[Screen:telecomando]
Container=models/telecomando.glb
Holdable=true
HoldPosition=(-0.25,-0.15,0.4)
HoldRotation=(15,-30,5)
DefaultView=main

[ScreenView:telecomando.main]
Model=models/telecom_screen.glb
Hotspots=btn_start

Proprietà Step Holdable

ParametroValore
HoldActionpick / release
HoldStateheld

Workflow Tipico

[Step 1] HoldAction=pick → Prendi
[Step 2] ScreenMode=true + HoldState=held → Usa
[Step 3] HoldAction=release → Posa

Console HoldableSystem

  • HoldableSystem.listHoldables()
  • HoldableSystem.pickObject('nome')
  • HoldableSystem.releaseObject('nome')
  • HoldableSystem.isHeld('nome')
  • HoldableSystem.debugInfo()

HoldPosition Default

  • X: -0.25 (sinistra)
  • Y: -0.15 (basso)
  • Z: 0.4 (davanti)

🔗 Integrazione Screen + Holdable

# Telecomando con schermo impugnabile
[Screen:remote] Holdable=true → ScreenSystem registra in HoldableSystem
HoldState=held + ScreenMode=true → Schermo interattivo mentre in mano
Hotspot OnClick=Action:x → Animazione su macchinari nella scena

🎮 StepController - Trigger Multipli

# Sorgenti Trigger
• screen: Hotspot UI schermo
• physical: Pulsante fisico 3D
• holdable: Azione oggetto in mano
• tutorial: Avanzamento manuale
• auto: AutoMode mobile

# Proprietà Step
AcceptTrigger_Screen=hotspot_id
AcceptTrigger_Physical=button_id
OnScreenTrigger=changeView:menu
OnPhysicalTrigger=changeView:menu;animate:pump

Console StepController

  • StepController.debugInfo()
  • StepController.listAcceptedTriggers()
  • StepController.simulateTrigger('screen','id')
  • StepController.registerPhysicalButton('name',cfg)
