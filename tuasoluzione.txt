🎯 PROBLEMA IDENTIFICATO!

  Il bug è in StepController.js linea 120 e 163:

  autoAdvance: config.autoAdvance !== false // Default TRUE ❌

  autoAdvance: true // ❌ SEMPRE true

  Cosa succede:
  1. Step "apri la porta" viene configurato con autoAdvance: true di default
  2. Quando viene accettato il trigger (anche da uno step precedente), lo step avanza automaticamente dopo 500ms
  3. L'utente NON ha MAI la possibilità di cliccare sulla chiave perché lo step avanza automaticamente

  Soluzione:

  Cambiare il default da autoAdvance: true a autoAdvance: false, e richiedere dichiarazione esplicita AutoAdvance=true nel tutorial quando serve.
