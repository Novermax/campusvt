🖐️ Sistema Oggetti Impugnabili (HoldableSystem)

Definizione Oggetto Impugnabile

[Screen:telecomando] Model=models/telecomando.glb Holdable=true HoldPosition=(-0.25,-0.15,0.4) HoldRotation=(15,-30,5) DefaultView=main

Parametri Holdable

ParametroFormatoDescrizione
HoldabletrueAbilita oggetto come impugnabile
HoldPosition(x,y,z)Posizione relativa camera (default: -0.25,-0.15,0.4)
HoldRotation(rx,ry,rz)Rotazione in gradi (default: 15,-30,5)

Parametri Step Tutorial

ParametroValoreDescrizione
HoldActionpickPrendi oggetto in mano
HoldActionreleaseRilascia oggetto (torna a posizione originale)
HoldStateheldRichiede che l'oggetto sia già in mano

Workflow Completo

# Step 1: Prendi oggetto [Step 2 - Prendi telecomando] Elemento=models/telecomando.glb Utensile=Mani HoldAction=pick Descrizione=Prendi il telecomando # Step 2: Usa schermo mentre in mano [Step 5 - Premi pulsante] Elemento=models/telecomando.glb ScreenMode=true RequiredHotspot=btn_start HoldState=held Descrizione=Premi START sul telecomando # Step 3: Rilascia oggetto [Step 10 - Posa telecomando] Elemento=models/telecomando.glb HoldAction=release Descrizione=Posa il telecomando

Comandi Console HoldableSystem

HoldableSystem.listHoldables() // Lista oggetti impugnabili HoldableSystem.isHeld('telecomando') // Verifica se in mano HoldableSystem.pickObject('telecomando') // Prendi oggetto HoldableSystem.releaseObject('telecomando') // Rilascia oggetto HoldableSystem.releaseAll() // Rilascia tutti HoldableSystem.getCurrentlyHeld() // Lista oggetti in mano HoldableSystem.debugInfo() // Debug completo

Note HoldPosition

  • X negativo: Sinistra della visuale (mano sinistra)
  • Y negativo: Verso il basso (altezza mano)
  • Z positivo: Davanti alla camera (distanza braccio)
