📖 Sintassi File Tutorial

Struttura Base

# Configurazione globale (opzionale) CameraPos=(-1.5, 0.5, -0.2) CameraTarget=(0, 0, 0) [Nome Tutorial] [Step N - Descrizione] Elemento=models/modello.glb Descrizione=Testo mostrato all'utente

Parametri Camera

ParametroSintassiDescrizione
CameraPos(x,y,z)Posizione assoluta camera
CameraTarget(x,y,z) o nome_oggettoPunto target camera
CameraZoom2.2Fattore zoom
CameraTransitionTime1.5Durata movimento (secondi)

Utensili

Utensile=Mani

Operazioni manuali

Utensile=ChiaveInglese

Chiave regolabile

Utensile=ChiaveBrugola

Chiave esagonale

Utensile=Aria

Pistola aria compressa con effetti particellari

Posizionamento Modelli

Posizione=nome_modello:(x,y,z) Rotazione=nome_modello:(rx,ry,rz)

ComandoSintassiUso

# Movimento normale Azione1=traslazione:(-0.2,0,0,0.8) # Movimento verso posizione corrente altro oggetto Azione1=traslazione:altro_oggetto,(0.1,0,0,0.8) # Movimento verso posizione ORIGINALE altro oggetto Azione1=traslazione:altro_oggetto_original,(0.1,0,0,0.8)

🔄 Sistema Drag & Drop

ParametroSintassiDescrizione
DragDroptrue/falseAbilita trascinamento
DragDropObjectsoggetto1,oggetto2Lista oggetti draggabili
DragDropDistance1.2Distanza snap automatico

Comandi Console Drag & Drop

// Abilita drag & drop DragDropSystem.enable(['oggetto1', 'oggetto2']) // Snap personalizzato a posizione corrente DragDropSystem.setCustomSnapTarget('oggetto', 'target') // Snap a posizione originale DragDropSystem.setCustomSnapTarget('oggetto', 'target_original') // Snap con offset DragDropSystem.setCustomSnapTarget('oggetto', 'target', new THREE.Vector3(0.1,0,0))

🐛 Comandi Console Debug

Camera e Orientamento

Scene3D.getCameraInfo() // Posizione camera corrente Scene3D.listAvailableObjects() // Oggetti disponibili Scene3D.applyCameraSettings(stepObject) // Applica settings camera

Gestione Modelli

Scene3D.findModelByName('nome_modello') // Trova modello Scene3D.exportCurrentModelPositions() // Esporta tutte le posizioni Scene3D.loadedModels // Lista modelli caricati

Sistema Tools

ToolsManager.getToolsState() // Stato strumenti ToolsManager.activateTool('aria') // Attiva tool ToolsManager.activateToolFromTutorial('Aria') // Attiva da nome tutorial

Sistema Particellare

ParticleSystem.testAirJet() // Test getto aria ParticleSystem.getStats() // Statistiche sistema ParticleSystem.clearAllEffects() // Rimuovi tutti gli effetti
