Agisci come sviluppatore senior specializzato in interfacce 3D touch-based, event handling avanzato e Three.js / WebGL (o framework equivalente).
L’obiettivo è progettare e implementare un sistema di gesture touch coerente, estendibile e robusto per l’interfaccia di Campus Virtual Training.

Contesto

L’applicazione visualizza scene 3D interattive con:

elementi 3D manipolabili

una legenda/toolbox con strumenti selezionabili

pulsanti UI

camera orbitale con pivot dinamico

interazione touch single-touch e multi-touch

Requisiti funzionali (vincolanti)

Implementare le seguenti gesture:

Touch singolo su elemento 3D

Seleziona l’elemento 3D

Il centro dell’elemento selezionato diventa il pivot della camera

Touch singolo su legenda

Seleziona il tool corrente (mano, chiave inglese, ecc.)

Touch singolo su elemento UI tipo pulsante

Trigger dell’azione associata al pulsante

Drag con un dito su elemento 3D

“Presa” dell’elemento

Movimentazione nello spazio

Rilascio alla fine del drag

Doppio tap con un dito su elemento 3D

Applica l’azione del tool selezionato all’elemento toccato

Touch + drag con due dita

Rotazione del punto di vista attorno al pivot corrente

Doppio tap con due dita

Selezione di un pivot custom

Pivot definito dal punto di raycast sull’elemento colpito

Il pavimento è escluso

Pinch (due dita aprire/chiudere)

Zoom camera in/out

Vincoli tecnici

Separare chiaramente:

gesture recognition

raycasting

camera control

object manipulation

tool logic

Nessuna gesture deve avere effetti collaterali su altre

Le priorità di input devono essere gestite esplicitamente (UI > oggetti 3D > camera)

Il sistema deve essere estendibile (aggiunta future gesture / tool)

Task richiesti all’LLM

Analisi

Identificare conflitti potenziali tra gesture

Definire una gerarchia di priorità degli eventi touch

Progettazione

Proporre una architettura a moduli (es. GestureManager, SelectionManager, CameraController, ToolController)

Definire uno state machine o schema equivalente per la gestione del contesto di input

Implementazione

Fornire codice esemplificativo (JS/TS) per:

riconoscimento gesture single-touch / multi-touch

raycasting touch → oggetto

cambio pivot camera

drag oggetti

doppio tap (1 dito / 2 dita)

pinch zoom

Usare pattern chiari e manutenibili

Validazione

Elencare casi limite (touch su UI + scena, perdita di touch, gesture incomplete)

Suggerire test manuali e automatici

Output atteso

Spiegazione tecnica concisa

Diagramma logico testuale o pseudo-codice dell’architettura

Codice chiaro, commentato solo dove necessario

Nessuna UI fittizia, nessuna ipotesi non dichiarata
