🏠home_config.txt - Configurazione Scenari

[NOME_SCENARIO] CameraPos=(-1.5, 0.5, -0.2) CameraTarget=(0, 0, 0) AmbientLight=0x404040,1.5 DirectionalLight=0xffffff,2.5,(-8, 15, 10) description_key=scenario_description_key image=menuimages/anteprima.png tutorial=scenes/Cartella/tutorial.txt model=models/componente.glb direction=-1,0,0 [ALTRO_SCENARIO] # ... altre configurazioni

Parametri Principali

  • CameraPos: Posizione iniziale camera
  • CameraTarget: Punto mira iniziale
  • AmbientLight: Luce ambiente (colore, intensità)
  • DirectionalLight: Luce direzionale

Configurazione Media

  • image: Anteprima scenario (PNG/JPG)
  • tutorial: Percorso file tutorial.txt
  • model: Modelli 3D (.glb, .obj, .stl)
  • direction: Direzione movimento (X,Y,Z)
